\# Pathfinding AI Project



A work-in-progress Python and Pygame project exploring pathfinding algorithms, algorithmic decision-making, and eventually reinforcement learning.



\## Current Features



\- Interactive grid

\- Place and remove walls

\- Place a start point

\- Place an end point

\- 60/120 FPS toggle

\- Neighbour generation with boundary and wall checking

\- Breadth-First Search (BFS) implementation

\- Path reconstruction using predecessor tracking

\- Basic GUI panel



\## Planned Features



\- Visualise BFS paths directly on the grid

\- Visualise searched/visited cells

\- Bidirectional BFS

\- Dijkstra's algorithm

\- A\* search

\- Compare algorithms using:

&#x20; - path length

&#x20; - nodes explored

&#x20; - execution time

\- Wall-placement strategy designed to maximise path length

\- Quoridor-inspired game mode

\- Computer-controlled opponent

\- Reinforcement learning agent



\## Controls



\- \*\*Left click\*\* - place a wall

\- \*\*S + Left click\*\* - place/move the start point

\- \*\*E + Left click\*\* - place/move the end point

\- \*\*Right click\*\* - remove a wall/start/end point

\- \*\*F\*\* - toggle FPS limit between 60 and 120



\## Current Status



The project is currently in early development. BFS has been implemented and tested, while the graphical controls for running and visualising algorithms are still being developed.
